A single line about a small, hard-won moment of pride — a test suite
finally going green at 2 a.m. after nine failed builds, and the quiet
one-word recognition that followed.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes `entry.txt` containing exactly one line (plus a trailing newline).

## Why this line

Pride rarely arrives as applause. It arrives at 2 a.m., after the ninth
failure, when the thing finally works — and the person you built it for
notices, even half asleep. The line is specific (nine failed builds, one
whispered word) because earned pride lives in the details, not in the
slogan. Nothing here is borrowed: the moment is invented, the feeling is
the point.
